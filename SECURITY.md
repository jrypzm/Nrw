# Security

yrs. keeps everything on your device. The Android app has no internet permission, and the iPhone web app stores its data only in your browser.

If you find a security or privacy problem, please don't open a public issue. Use **[private vulnerability reporting](https://github.com/jrypzm/yrs/security/advisories/new)** instead, with the steps to reproduce it and the version you tested.

You'll get a reply as soon as possible, and credit in the release notes if you'd like it.

Only the [latest release](https://github.com/jrypzm/yrs/releases/latest) receives fixes.
